# . About

The **Security Ops** extension for **Chrome**, **Firefox**, and **Edge** is your all-in-one shield for online privacy, security, and performance. It delivers a suite of powerful features designed to protect your browsing experience while enhancing speed and security.

With features like ad and malware blocking, fingerprint protection, privacy redirects, and more; all wrapped in a sleek, fully customizable package. **Security Ops** ensures your online experience is fast, secure, and private.

# . 🛡️ **Key Features:**

- **Ad, Tracker, and Malware Blocking:** Blocks requests to domains listed in a regularly updated hosts file sourced from Codeberg.
- **Fingerprint Protection:** Prevents fingerprinting techniques, including Canvas, WebGL, and AudioContext spoofing.
- **Location Tracking Protection:** Disables geolocation tracking to keep your location private.
- **Customizable Dark Theme:** Apply a smooth, dark interface with a variety of customizable font colors.
- **HTTPS & Parameter Stripping:** Automatically enforces HTTPS and strips tracking parameters from URLs for enhanced privacy.
- **Privacy-Friendly Redirects:** Redirects popular sites like YouTube, Google, and Reddit to more privacy-conscious alternatives.
- **Automatic Hosts Updates:** The extension automatically updates its hosts file every week for the latest protection.
- **Panic Button:** Instantly clears browsing data (history, cookies, cache) with the click of a button.
- **Proxy Support:** Route your traffic through a proxy server for enhanced privacy.
- **Dashboard View:** Visualize blocked requests and gather privacy statistics with the intuitive dashboard.

The extension proudly uses the official **Security Ops®** logo, and the source code is open-source, licensed under **GPL v3**. 😊

# . 🏗️  Project Structure

| **File**                | **Description**                                                                                 |
|-------------------------|-------------------------------------------------------------------------------------------------|
| `manifest.json`          | Configuration file for the extension, including permissions and scripts.                        |
| `background.js`          | Manages blocking, redirects, proxy configuration, HTTPS enforcement, and logging.               |
| `content.js`             | Injects CSS for the dark theme, overrides APIs for fingerprinting, and adjusts the referrer policy. |

For more information, visit [extension.securityops.co](https://extension.securityops.co).
