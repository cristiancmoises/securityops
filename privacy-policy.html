Privacy Policy

Your privacy is our top priority. Learn how Security Ops protects your data and respects your privacy.

Last Updated: January 14, 2025

Privacy-First Approach

Zero Data Collection

Security Ops does not collect, store, transmit, or share any personal data, browsing history, or user information. Your privacy is completely protected.

Security Ops is designed with privacy as the fundamental principle. Unlike many other browser extensions that collect user data for analytics, advertising, or other purposes, Security Ops operates entirely locally on your device without any external data transmission.

This privacy policy explains our commitment to protecting your privacy and outlines the technical measures we implement to ensure your data remains secure and private.

Data We Do NOT Collect

Security Ops explicitly does not collect any of the following information:

  • Personal Information: Names, email addresses, phone numbers, or any personally identifiable information
  • Browsing History: Websites visited, pages viewed, or browsing patterns
  • Search Queries: Search terms or queries entered in search engines
  • Location Data: Geographic location, IP addresses, or location-based information
  • Device Information: Device identifiers, hardware specifications, or system information
  • Usage Analytics: Extension usage patterns, feature usage, or behavioral data
  • Cookies or Tracking: No cookies, tracking pixels, or similar technologies are used
  • Network Traffic: Content of web requests, responses, or network communications
Technical Implementation

Our extension operates entirely within your browser's local environment. All processing, filtering, and blocking decisions are made locally without any external communication.

Local Data Storage

Security Ops stores certain configuration data locally on your device to maintain your preferences and settings. This data never leaves your device and is not transmitted to any external servers.

Data Type Purpose Storage Location Transmission
Extension Settings Store user preferences (blocking categories, theme settings) Browser Local Storage Never transmitted
Proxy Configuration Store proxy server settings for TORANDO and custom proxies Browser Local Storage Never transmitted
Whitelist Domains Store user-defined whitelisted domains Browser Local Storage Never transmitted
Blocking Statistics Count blocked requests for user information Browser Local Storage Never transmitted
Blocklist Cache Cache downloaded blocklists for offline operation Browser Local Storage Never transmitted
Data Removal

All locally stored data can be completely removed by uninstalling the extension or clearing your browser's extension data. No traces remain on external servers.

Blocklist Updates

Security Ops downloads blocklists from reputable sources to maintain up-to-date protection against ads, trackers, and malware. These downloads are performed anonymously and do not include any identifying information.

Blocklist Sources:

  • Mullvad VPN DNS Blocklists: Official blocklists for ads, trackers, malware, gambling, adult content, and social media
  • EasyList: Community-maintained ad blocking filters
  • EasyPrivacy: Privacy protection filters for tracker blocking
  • Additional Security Lists: Malware and phishing protection lists
Anonymous Downloads

Blocklist updates are downloaded using standard HTTP requests without any user identification, tracking headers, or personal information. The requests are indistinguishable from regular web traffic.

IP Address Display

Security Ops includes an optional feature to display your current IP address in the popup interface. This feature is designed to help users verify their proxy or VPN connections.

How IP Detection Works:

  • IP address is retrieved from public IP detection services
  • Multiple fallback services are used for reliability
  • No personal information is sent with IP detection requests
  • IP address is displayed locally and never stored or transmitted
  • Feature can be completely disabled in settings
User Control

The IP display feature is entirely optional and can be disabled at any time. When disabled, no IP detection requests are made.

Third-Party Services

Security Ops interacts with certain third-party services to provide its functionality. These interactions are designed to maintain your privacy and anonymity.

Service Interactions:

Service Purpose Data Sent Privacy Protection

Security Measures

Security Ops implements multiple security measures to protect your privacy and ensure the integrity of the extension.

Technical Security:

  • Local Processing: All filtering and blocking decisions are made locally
  • No External Communication: No analytics, telemetry, or tracking communications
  • Secure Storage: Settings stored using browser's secure storage APIs
  • Content Security Policy: Strict CSP prevents code injection attacks
  • Minimal Permissions: Only requests necessary browser permissions
  • Open Source Principles: Transparent operation and code review
Privacy by Design

Security Ops is built with privacy by design principles, ensuring that privacy protection is embedded into every aspect of the extension's architecture and operation.

User Rights and Control

As a Security Ops user, you have complete control over your data and privacy settings.

Your Rights:

  • Data Access: All your data is stored locally and accessible to you
  • Data Portability: Export your settings and whitelist at any time
  • Data Deletion: Completely remove all data by uninstalling the extension
  • Feature Control: Enable or disable any feature according to your preferences
  • Transparency: Full visibility into what data is stored and how it's used
  • No Consent Required: No personal data collection means no consent forms
Data Portability

You can export your Security Ops settings, whitelist, and configuration at any time through the extension's settings page or by accessing your browser's extension storage.

Compliance and Standards

Security Ops is designed to comply with major privacy regulations and standards worldwide.

Regulatory Compliance:

  • GDPR (EU): No personal data processing, no consent required
  • CCPA (California): No personal information collection or sale
  • PIPEDA (Canada): No personal information handling
  • Privacy Act (Australia): No personal information collection
  • LGPD (Brazil): No personal data processing
Compliance by Design

By not collecting any personal data, Security Ops automatically complies with privacy regulations worldwide without requiring complex compliance procedures.

Changes to This Policy

We may update this privacy policy from time to time to reflect changes in our practices or for other operational, legal, or regulatory reasons.

Policy Updates:

  • Material changes will be clearly communicated to users
  • Updated policy will be available on our website and in the extension
  • Version history will be maintained for transparency
  • Users will be notified of significant changes through the extension interface
Continued Use

Continued use of Security Ops after policy updates constitutes acceptance of the new terms. However, since we don't collect personal data, policy changes typically have minimal impact on users.
