Features

Everything you need, nothing you don't

Built on Manifest V3 with state-of-the-art security hardening. No remote code execution. No telemetry. Just protection.

Block Ads & Trackers

Hagezi DNS blocklists with 7 categories: ads, trackers, malware, gambling, adult, social, and aggressive blocking modes.

Site-Wide Dark Theme

Apply a dark theme to every website you visit, with 6 accent colors. No more retina-burning white pages.

Tor & Proxy Support

One-click TORANDO mode routes traffic through your local Tor SOCKS5 proxy. Full SOCKS4/5, HTTP, HTTPS support.

YouTube Ad-Block

Multi-layer YouTube ad blocking: network rules, player JSON scrubbing, DOM pruning, and auto-skip for unblocked ads.

Strip Tracking Params

Auto-removes utm_*, fbclid, gclid, and 12 other tracking parameters from every URL before navigation.

Search & Site Redirects

Optional redirects: Google to SecurityOps Web, YouTube to Invidious, Reddit to Redlib. Privacy-respecting alternatives.

Get Started

Install in 2 minutes

Free forever. Open source under GPL-3.0. No account required. No telemetry. No data collection.

Chrome / Edge

  1. Open chrome://extensions
  2. Enable Developer Mode
  3. Load Unpacked → select chrome/ folder

Firefox

  1. Open about:debugging#/runtime/this-firefox
  2. Click "Load Temporary Add-on"
  3. Select firefox/manifest.json
